Plan the perfect family game night with the help of AI! This interactive web app suggests games based on your family’s preferences, group size, and mood — making every game night fun, personalized, and stress-free.

🔧 Tech Stack
	•	HTML (59%) – for building a clean and responsive user interface
	•	Python (41%) – for the AI logic, game suggestion engine, and backend functionalities

✨ Features
	•	AI-powered game recommendations
	•	Custom filters based on age groups, number of players, and game types
	•	Simple and friendly user interface
	•	Lightweight and fast

🚀 How It Works
	1.	Input your family’s preferences
	2.	The AI processes your input using a smart matching algorithm
	3.	Get curated game suggestions for a memorable night!

📦 How to Run
	1.	Clone the repo
	2.	Run the Python backend
	3.	Open the HTML file in a browser
	4.	Enjoy game night planning!
